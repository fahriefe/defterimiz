# Üçüncü taraf lisansları

Bu proje, kendi lisansları altında dağıtılan açık kaynak bileşenler kullanır. Bunlar [LICENSE](LICENSE) dosyasındaki kısıtlamalara tabi **değildir**; kendi lisanslarına tabidir.

| Bileşen | Lisans |
|---|---|
| Expo `blank-typescript` şablonu (Copyright © 2015-present 650 Industries, Inc.) | MIT |
| Expo, React, React Native, React Native Web, Firebase JS SDK, react-native-svg ve diğer npm paketleri | Her paketin kendi lisansı (çoğunlukla MIT / Apache-2.0); tam liste için `npm ls` ya da `package-lock.json` |
| **Nunito** yazı tipi ([@expo-google-fonts/nunito](https://www.npmjs.com/package/@expo-google-fonts/nunito)) | SIL Open Font License 1.1 |
| **Caveat** yazı tipi ([@expo-google-fonts/caveat](https://www.npmjs.com/package/@expo-google-fonts/caveat)) | SIL Open Font License 1.1 |

Hediye sesleri ve uygulama simgesi bu proje için kodla üretilmiştir.
